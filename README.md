# 📋 Task Manager

A full-stack **Task Management Web Application** built using the **MERN Stack** where admins can assign and manage tasks while team members can track and update their work progress.

> ## Live Demo :
<ul> https://task-manager-pi-eight-72.vercel.app/ </ul>

---

> ## Features :

### 👨‍💼 Admin Features
- Admin authentication using invite token
- Create and assign tasks to team members
- Update and delete tasks
- Manage team members
- Download task and user reports
- View analytics:
  - Total Tasks
  - Pending Tasks
  - Completed Tasks
  - Ongoing Tasks

### 👨‍💻 Team Member Features
- View assigned tasks
- Track task progress
- Update checklist/task status
- Dashboard for task overview

### 🔐 Authentication & Security
- Login & Signup system
- JWT Authentication
- Protected Routes
- Role-Based Access Control (Admin/User)
- Secure password hashing using Bcrypt

### 🎨 Additional Features
- Upload profile pictures using Cloudinary
- Responsive UI using Tailwind CSS
- Toast notifications
- Interactive charts using Recharts
